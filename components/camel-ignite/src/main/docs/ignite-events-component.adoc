The Ignite Events endpoint is one of camel-ignite endpoints which allows you to https://apacheignite.readme.io/docs/events[receive events] from the Ignite cluster by creating a local event listener.

The Exchanges created by this consumer put the received Event object into the body of the _IN_ message.

== Usage

The component needs an Ignite node: xref:ignite-summary.adoc[Ignite] describes the ways to give it one.

The consumer receives the events of the types in `events`, the names of the `EventType` constants, separated by
commas without spaces. Ignite records only the event types that its configuration includes (`includeEventTypes`
of the `IgniteConfiguration`):

[source,yaml]
----
- route:
    from:
      uri: ignite-events:cacheEvents
      parameters:
        events: EVT_CACHE_OBJECT_PUT,EVT_CACHE_OBJECT_REMOVED
      steps:
        - log:
            message: "Event: ${body}"
----
