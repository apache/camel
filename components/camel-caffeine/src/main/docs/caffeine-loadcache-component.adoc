The Caffeine LoadCache component enables you to perform caching operations using
the LoadingCache from Caffeine.

Maven users will need to add the following dependency to
their `pom.xml` for this component:

[source,xml]
------------------------------------------------------------
<dependency>
    <groupId>org.apache.camel</groupId>
    <artifactId>camel-caffeine</artifactId>
    <version>x.x.x</version>
    <!-- use the same version as your Camel core version -->
</dependency>
------------------------------------------------------------

== Usage

A loading cache has a `cacheLoader`, which makes the value of a key that is not in the cache yet.
The first GET of a key calls the loader, and the next GETs of that key get the value from the cache.
The cache is shared by name, so all `caffeine-loadcache:prices` endpoints use the same cache.

In this example, the loader is a Groovy closure, and the key comes from the `CamelCaffeineKey` header:

[source,yaml]
----
- beans:
    - name: priceLoader
      type: com.github.benmanes.caffeine.cache.CacheLoader
      scriptLanguage: groovy
      script: "{ key -> 'price of ' + key } as com.github.benmanes.caffeine.cache.CacheLoader"
- route:
    from:
      uri: direct:price
      steps:
        - setHeader:
            name: CamelCaffeineKey
            expression:
              simple:
                expression: "${header.product}"
        - to:
            uri: caffeine-loadcache:prices
            parameters:
              action: GET
              cacheLoader: "#priceLoader"
        - log:
            message: "${body}"
----

The operations and their result headers are the same as for the xref:caffeine-cache-component.adoc[Caffeine Cache] component.
