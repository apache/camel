The Saga component provides a bridge to execute custom actions within a route using the Saga EIP.

The component should be used for advanced tasks, such as deciding to complete or compensate a Saga
with completionMode set to *MANUAL*.

Refer to the xref:eips:saga-eip.adoc[Saga EIP] documentation for help on using sagas in common scenarios.

== Usage

The two endpoints are `saga:complete` and `saga:compensate`.
A route that is part of a saga with the completion mode `MANUAL` sends to one of them to end the saga.
Camel then calls the completion or the compensation endpoint of the saga.

The example below uses the in-memory saga service, which is not meant for production.
The first route starts a saga for an order and asks for the payment.
The second route gets the payment result, in the same saga: it completes the saga when the order is paid,
and compensates it otherwise.
The `orderId` option is a header in the completion and compensation routes.

[source,yaml]
----
- beans:
    - name: sagaService
      type: org.apache.camel.saga.InMemorySagaService
- route:
    from:
      uri: direct:order
      steps:
        - saga:
            completionMode: MANUAL
            timeout: 1m
            completion: direct:orderCompleted
            compensation: direct:orderCancelled
            option:
              - key: orderId
                expression:
                  simple:
                    expression: "${header.orderId}"
        - to:
            uri: seda:payment
- route:
    from:
      uri: seda:paymentResult
      steps:
        - saga:
            propagation: MANDATORY
        - choice:
            when:
              - expression:
                  simple:
                    expression: "${body} == 'paid'"
                steps:
                  - to:
                      uri: saga:complete
            otherwise:
              steps:
                - to:
                    uri: saga:compensate
----
