The Alibaba Cloud Function Compute (FC) component allows you to invoke functions and retrieve function metadata.

Maven users will need to add the following dependency to their `pom.xml`
for this component:

[source,xml]
----
<dependency>
    <groupId>org.apache.camel</groupId>
    <artifactId>camel-alibaba-fc</artifactId>
    <version>x.x.x</version>
    <!-- use the same version as your Camel core version -->
</dependency>
----

== Usage

=== Operations

The component supports the following operations:

* `invokeFunction` - invoke a function with a payload (producer)
* `getFunction` - retrieve function metadata (producer)

=== Payload of invokeFunction

The message body is the payload of the function. A `String` is sent in UTF-8, and a `byte[]`, an `InputStream` or a
file is sent as its bytes, so binary data is kept. Without a body the function is invoked with an empty payload. A `Map`
or a POJO does not convert to bytes and fails with an `InvalidPayloadException`, so marshal it first, for example to
JSON with `marshal().json()`.

=== Function error

A function error that Function Compute returns with the status 200 does not fail the exchange. The producer sets the
`CamelAlibabaFcFunctionError` header to its error type, such as `UnhandledInvocationError`. A route detects such a
function error by this header, for example in a choice.

=== Endpoint of Function Compute

The `endpoint` option is the endpoint of Function Compute for your Alibaba Cloud account and region. The public
endpoint has the form `<account ID>.<region ID>.fc.aliyuncs.com`, for example `12345.cn-hangzhou.fc.aliyuncs.com` for
the account ID 12345 and the region cn-hangzhou. The internal endpoint has the form
`<account ID>.<region ID>-internal.fc.aliyuncs.com`.

=== Producer example

[tabs]
====
Java::
+
[source,java]
----
from("direct:start")
    .setBody(constant("{\"name\":\"camel\"}"))
    .to("alibaba-fc:invokeFunction?serviceName=my-service&functionName=my-function&endpoint=12345.cn-hangzhou.fc.aliyuncs.com&accessKey=RAW(accessKey)&secretKey=RAW(secretKey)");
----

YAML::
+
[source,yaml]
----
- route:
    from:
      uri: direct:start
      steps:
        - setBody:
            expression:
              constant:
                expression: '{"name":"camel"}'
        - to:
            uri: alibaba-fc:invokeFunction
            parameters:
              serviceName: my-service
              functionName: my-function
              endpoint: 12345.cn-hangzhou.fc.aliyuncs.com
              accessKey: "{{alibaba.access-key}}"
              secretKey: "{{alibaba.secret-key}}"
----
====
