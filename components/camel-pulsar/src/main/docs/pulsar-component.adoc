== Usage

Set the service URL of the Pulsar cluster on the component, for example in `application.properties`:

[source,properties]
----
camel.component.pulsar.service-url = pulsar://localhost:6650
----

The following routes send a message to the `orders` topic every five seconds, and consume the topic with the
`order-processor` subscription:

[source,yaml]
----
- route:
    from:
      uri: timer:orders
      parameters:
        period: 5000
      steps:
        - setBody:
            expression:
              simple:
                expression: "Order ${exchangeId}"
        - to:
            uri: pulsar:persistent://public/default/orders
- route:
    from:
      uri: pulsar:persistent://public/default/orders
      parameters:
        subscriptionName: order-processor
      steps:
        - log:
            message: "Received ${body}"
----

=== Message body

The producer sends the body as a byte array: text, bytes, a stream or a file are sent as their content. A body that
does not convert to a byte array, such as a `Map`, a `List`, a number or a POJO, fails, and so does no body: marshal it
first, for example to JSON with `marshal().json()`. The consumer gives the payload as a byte array, so convert or
unmarshal it in the route.

Before Camel 4.24 such a body was sent with Java serialization, which only a Java client that deserializes it can
read. The deprecated `allowJavaSerializedObject` option turns this back on for compatibility, and will be removed.

=== Producer sequence ids and deduplication

With a `producerName` and deduplication enabled on the broker, the producer continues the sequence ids after the
last sequence id the broker stored for that producer name, also after a restart, so the broker does not drop the
messages of the new run as duplicates. Set `initialSequenceId` only to start from a given sequence id: every start
then begins after that value again, so with a `producerName` and deduplication the broker drops the messages until
their sequence ids pass the last one it stored. Leave the option unset to let the client continue.
