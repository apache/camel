This component integrates with Google Cloud Vertex AI, supporting both Google's native models (Gemini, Imagen) and partner models (Claude, Llama, Mistral) through the rawPredict API.

== Prerequisites

* A Google Cloud Platform account with Vertex AI API enabled
* A service account with appropriate permissions, or Application Default Credentials configured

For setup instructions, see https://cloud.google.com/vertex-ai/docs[Vertex AI Documentation].

== URI Format

----
google-vertexai:projectId:location:modelId[?options]
----

* `projectId` - Your GCP project ID
* `location` - Region where the model is available (e.g., `us-central1`, `us-east5`)
* `modelId` - Model identifier (e.g., `gemini-2.0-flash`, `claude-sonnet-4@20250514`)

== Authentication

The component supports two authentication methods:

1. *Service Account Key File* - Set the `serviceAccountKey` parameter to a file path:
+
----
serviceAccountKey=file:/path/to/service-account.json
----

2. *Application Default Credentials* - If no key is provided, the component uses ADC automatically.

== Operations

=== Google Models

Use these operations with Gemini, Imagen, and other Google models:

[cols="1,3"]
|===
|Operation |Description

|`generateText`
|Generate text from a prompt

|`generateChat`
|Generate chat responses

|`generateChatStreaming`
|Generate streaming chat responses (accumulated text returned with chunk count)

|`generateCode`
|Generate code from a description

|`generateImage`
|Generate images using Imagen models

|`generateEmbeddings`
|Generate text embeddings using embedding models (single text or batch)

|`generateMultimodal`
|Generate content from multimodal inputs (text + images/video/audio)
|===

=== Partner Models

Use `rawPredict` and `streamRawPredict` for Claude, Llama, and Mistral models:

[cols="1,3"]
|===
|Operation |Description

|`rawPredict`
|Send requests to partner models via the Prediction Service API

|`streamRawPredict`
|Send streaming requests to partner models (accumulated response with chunk count)
|===

Partner models require the `publisher` parameter: `anthropic`, `meta`, or `mistralai`.

=== System Instruction and Safety Settings

The `generateText`, `generateChat`, `generateChatStreaming`, `generateCode` and `generateMultimodal` operations send the
system instruction of the `CamelGoogleVertexAISystemInstruction` header, and the safety settings of the
`CamelGoogleVertexAISafetySettings` header, a `List` of `com.google.genai.types.SafetySetting`.
The response sets the `CamelGoogleVertexAISafetyRatings` header with the safety ratings of the answer.

._Java-only: the safety settings are Java objects_
[source,java]
----
from("direct:prompt")
    .setHeader("CamelGoogleVertexAISystemInstruction", constant("You answer in one sentence"))
    .setHeader("CamelGoogleVertexAISafetySettings", constant(List.of(SafetySetting.builder()
            .category(HarmCategory.Known.HARM_CATEGORY_HARASSMENT)
            .threshold(HarmBlockThreshold.Known.BLOCK_LOW_AND_ABOVE)
            .build())))
    .to("google-vertexai:my-project:us-central1:gemini-2.0-flash")
    .log("${body}");
----

When the safety filters block the prompt, the response has no text: the body is null, and the
`CamelGoogleVertexAIContentBlocked` header is `true`, with the safety ratings of the prompt in the
`CamelGoogleVertexAISafetyRatings` header. When they stop the answer, the exchange fails with an `IllegalArgumentException`
that names the finish reason, such as `SAFETY`.

=== Image Generation with Imagen

[tabs]
====
Java::
+
[source,java]
----
from("direct:image")
    .setBody(constant("A sunset over mountains"))
    .setHeader("CamelGoogleVertexAIImageNumberOfImages", constant(1))
    .to("google-vertexai:my-project:us-central1:imagen-3.0-generate-002?operation=generateImage")
    .log("Generated ${body.size()} image(s)");
----

XML::
+
[source,xml]
----
<route>
  <from uri="direct:image"/>
  <setBody>
    <constant>A sunset over mountains</constant>
  </setBody>
  <setHeader name="CamelGoogleVertexAIImageNumberOfImages">
    <constant resultType="java.lang.Integer">1</constant>
  </setHeader>
  <to uri="google-vertexai:my-project:us-central1:imagen-3.0-generate-002?operation=generateImage"/>
  <log message="Generated ${body.size()} image(s)"/>
</route>
----

YAML::
+
[source,yaml]
----
- route:
    from:
      uri: direct:image
      steps:
        - setBody:
            constant: A sunset over mountains
        - setHeader:
            name: CamelGoogleVertexAIImageNumberOfImages
            constant: 1
        - to:
            uri: google-vertexai:my-project:us-central1:imagen-3.0-generate-002
            parameters:
              operation: generateImage
        - log:
            message: "Generated ${body.size()} image(s)"
----
====

The body will contain a `List<Image>` with the generated images. Each `Image` has `imageBytes()` and `mimeType()` methods.

=== Multimodal Input (Image + Text)

[tabs]
====
Java::
+
[source,java]
----
from("direct:multimodal")
    .setHeader("CamelGoogleVertexAIPrompt", constant("Describe this image"))
    .setHeader("CamelGoogleVertexAIMediaGcsUri", constant("gs://my-bucket/photo.jpg"))
    .setHeader("CamelGoogleVertexAIMediaMimeType", constant("image/jpeg"))
    .to("google-vertexai:my-project:us-central1:gemini-2.0-flash?operation=generateMultimodal")
    .log("${body}");
----

XML::
+
[source,xml]
----
<route>
  <from uri="direct:multimodal"/>
  <setHeader name="CamelGoogleVertexAIPrompt">
    <constant>Describe this image</constant>
  </setHeader>
  <setHeader name="CamelGoogleVertexAIMediaGcsUri">
    <constant>gs://my-bucket/photo.jpg</constant>
  </setHeader>
  <setHeader name="CamelGoogleVertexAIMediaMimeType">
    <constant>image/jpeg</constant>
  </setHeader>
  <to uri="google-vertexai:my-project:us-central1:gemini-2.0-flash?operation=generateMultimodal"/>
  <log message="${body}"/>
</route>
----

YAML::
+
[source,yaml]
----
- route:
    from:
      uri: direct:multimodal
      steps:
        - setHeader:
            name: CamelGoogleVertexAIPrompt
            constant: Describe this image
        - setHeader:
            name: CamelGoogleVertexAIMediaGcsUri
            constant: "gs://my-bucket/photo.jpg"
        - setHeader:
            name: CamelGoogleVertexAIMediaMimeType
            constant: image/jpeg
        - to:
            uri: google-vertexai:my-project:us-central1:gemini-2.0-flash
            parameters:
              operation: generateMultimodal
        - log:
            message: "${body}"
----
====

You can also pass inline image bytes via the `CamelGoogleVertexAIMediaData` header instead of a GCS URI.
The `CamelGoogleVertexAIMediaMimeType` header is then required: without it the exchange fails.

When neither the `CamelGoogleVertexAIMediaData` nor the `CamelGoogleVertexAIMediaGcsUri` header is set, the message body is used:

* A `String` body is the text prompt when the `CamelGoogleVertexAIPrompt` header is not set.
* Any other body is the media: bytes, an `InputStream`, a `File`, a `Path` or the file of a file consumer, read with the type converter.
Its MIME type is the `CamelGoogleVertexAIMediaMimeType` header or, for a file, the one of its file name extension (such as `image/png` for `photo.png`).
When there is none, the exchange fails, so set the header for bytes or a stream, such as from the `Content-Type` of an HTTP request.
* An empty or blank `String`, or an empty byte array, is not media: the request has the prompt only, so a body that an earlier step left does not fail it.

For example, to describe the images dropped in a folder:

[tabs]
====
Java::
+
[source,java]
----
from("file:images")
    .setHeader("CamelGoogleVertexAIPrompt", constant("Describe this image"))
    .to("google-vertexai:my-project:us-central1:gemini-2.0-flash?operation=generateMultimodal")
    .log("${body}");
----

YAML::
+
[source,yaml]
----
- route:
    from:
      uri: file:images
      steps:
        - setHeader:
            name: CamelGoogleVertexAIPrompt
            expression:
              constant:
                expression: Describe this image
        - to:
            uri: google-vertexai:my-project:us-central1:gemini-2.0-flash
            parameters:
              operation: generateMultimodal
        - log:
            message: "${body}"
----
====

=== Claude with Custom Request

For more control, pass a JSON body. The request can be a `String`, bytes, a stream or a file (such as a JSON file or the body of an HTTP request), which is read as text, or a `Map`, which is written as JSON.
Text that is not a JSON object is a plain text prompt, which the component wraps in the format of the publisher.
For publisher `anthropic`, a request without `anthropic_version` gets the one of the `CamelGoogleVertexAIAnthropicVersion` header, or else of the `anthropicVersion` option.

._Java-only: requires Java text block for JSON request body_

[source,java]
----
from("direct:claude")
    .process(exchange -> {
        String json = """
            {
                "anthropic_version": "vertex-2023-10-16",
                "max_tokens": 512,
                "messages": [{"role": "user", "content": "Write a haiku"}]
            }
            """;
        exchange.getMessage().setBody(json);
    })
    .to("google-vertexai:my-project:us-east5:claude-sonnet-4@20250514?operation=rawPredict&publisher=anthropic")
    .log("${body}");
----

== Supported Models

=== Google Models

Use with `generateText`, `generateChat`, `generateChatStreaming`, `generateCode`, `generateImage`, `generateEmbeddings`, or `generateMultimodal`:

* *Gemini*: `gemini-2.5-pro`, `gemini-2.5-flash`, `gemini-2.0-flash`, `gemini-1.5-pro`, `gemini-1.5-flash`
* *Imagen*: `imagen-4.0-generate-preview-05-20`, `imagen-3.0-generate-002`
* *Gemma*: `gemma-3-27b-it`, `gemma-2-27b-it`, `gemma-2-9b-it`
* *Embeddings*: `text-embedding-005`, `text-embedding-004`

=== Partner Models

Use with `rawPredict` or `streamRawPredict` and the appropriate `publisher`:

[cols="1,2,2"]
|===
|Publisher |Models |Regions

|`anthropic`
|`claude-sonnet-4@20250514`, `claude-opus-4@20250514`, `claude-3-5-haiku@20241022`
|us-east5, europe-west1

|`meta`
|`llama-4-maverick-17b-128e-instruct-maas`, `llama-3.3-70b-instruct-maas`
|us-central1

|`mistralai`
|`mistral-medium-3`, `mistral-small-2503`, `codestral-2`
|us-central1, europe-west4
|===

See `VertexAIModels` for all available model identifiers.
