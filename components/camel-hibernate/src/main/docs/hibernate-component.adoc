= Hibernate Component
:doctitle: Hibernate
:shortname: hibernate
:artifactid: camel-hibernate
:description: Perform database operations using Hibernate ORM supporting both JPA-backed and Native Hibernate modes.
:since: 4.23
:supportlevel: Preview
:tabs-sync-option:
:component-header: Both producer and consumer are supported

*Since Camel {since}*

*{component-header}*

The Hibernate component provides integration with relational databases through Hibernate ORM and Jakarta Persistence (JPA).
It can persist or merge entities, run JPQL, named, or native queries, and poll the database for batch processing.
JPA-backed mode uses an `EntityManagerFactory` and the `camel-jpa` `TransactionStrategy`. Native Hibernate mode uses a
`SessionFactory` directly.

Maven users will need to add the following dependency to their `pom.xml`
for this component:

[source,xml]
----
<dependency>
    <groupId>org.apache.camel</groupId>
    <artifactId>camel-hibernate</artifactId>
    <version>x.x.x</version>
    <!-- use the same version as your Camel core version -->
</dependency>
----

== Usage

=== Producer operations

When acting as a producer, the Hibernate endpoint persists or queries entities depending on the Exchange message body or configured URI parameters:

* **Persist / Merge**: If the body contains an entity instance (or collection of entities), sending the exchange to the endpoint persists or updates the entity in the database. If the body is `null` and no query is configured, the producer logs a warning and sets the outbound body to `null`.
* **Query Execution**: If a query is provided via URI options (`query`, `namedQuery`, or `nativeQuery`) or overridden via the `CamelHibernateQuery` header, the producer executes the query and returns the result as the outbound body.

You can use `query`, `namedQuery` or `nativeQuery` on the producer. `query` (JPQL) and `nativeQuery` (SQL) text is inspected for `INSERT`, `UPDATE`, or `DELETE` so those statements run with `executeUpdate()` and return the update count. Named query names are not treated as query text. To run a named mutation query you must set `useExecuteUpdate=true`.

=== Consumer operations

When acting as a consumer, the endpoint polls the database periodically using a configured query (`query`, `namedQuery`, or `nativeQuery`).

* **Consume and Delete**: Setting `consumeDelete=true` deletes consumed entities from the database after processing to avoid re-processing during subsequent polling cycles.
* **Maximum Results**: Use `maximumResults` to limit the number of records returned per poll batch.

When `consumeDelete=true`, the consumer uses reflection to detach `@ManyToOne`, `@OneToOne`, and `@ManyToMany` associations (skipping uninitialized lazy proxies) so flush does not re-persist the deleted entity through a parent collection. This is a best-effort approach and may not cover every mapping style.

== Execution modes

=== JPA-backed mode

In JPA-backed mode, the component uses Jakarta Persistence (`EntityManagerFactory`) and a Spring-managed `TransactionStrategy` from `camel-jpa`.

=== Native Hibernate mode

In Native Hibernate mode, the component uses a Hibernate `SessionFactory` directly (the Hibernate `Session` is used as a JPA `EntityManager`).

== Examples

=== Persisting and querying entities

[tabs]
====
Java::
+
[source,java]
----
from("direct:persist")
    .to("hibernate:org.apache.camel.component.hibernate.Item");

from("direct:query")
    .to("hibernate:org.apache.camel.component.hibernate.Item?query=SELECT i FROM Item i");
----

XML::
+
[source,xml]
----
<route>
  <from uri="direct:persist"/>
  <to uri="hibernate:org.apache.camel.component.hibernate.Item"/>
</route>
<route>
  <from uri="direct:query"/>
  <to uri="hibernate:org.apache.camel.component.hibernate.Item?query=SELECT i FROM Item i"/>
</route>
----

YAML::
+
[source,yaml]
----
- route:
    from:
      uri: direct:persist
      steps:
        - to:
            uri: hibernate:org.apache.camel.component.hibernate.Item
- route:
    from:
      uri: direct:query
      steps:
        - to:
            uri: hibernate:org.apache.camel.component.hibernate.Item
            parameters:
              query: SELECT i FROM Item i
----
====

=== Named mutation queries

Named `INSERT`/`UPDATE`/`DELETE` queries require `useExecuteUpdate=true` because Camel does not inspect the named query name as query text:

[tabs]
====
Java::
+
[source,java]
----
from("direct:deleteAll")
    .to("hibernate:org.apache.camel.component.hibernate.Item?namedQuery=Item.removeAll&useExecuteUpdate=true");
----

XML::
+
[source,xml]
----
<route>
  <from uri="direct:deleteAll"/>
  <to uri="hibernate:org.apache.camel.component.hibernate.Item?namedQuery=Item.removeAll&amp;useExecuteUpdate=true"/>
</route>
----

YAML::
+
[source,yaml]
----
- route:
    from:
      uri: direct:deleteAll
      steps:
        - to:
            uri: hibernate:org.apache.camel.component.hibernate.Item
            parameters:
              namedQuery: Item.removeAll
              useExecuteUpdate: true
----
====

=== JPA-backed mode example

[tabs]
====
Java::
+
[source,java]
----
HibernateComponent component = new HibernateComponent();
component.setEntityManagerFactory(entityManagerFactory);
context.addComponent("hibernate", component);

from("direct:jpaPersist")
    .to("hibernate:org.apache.camel.component.hibernate.Item?usePersist=true");

from("hibernate:org.apache.camel.component.hibernate.Item?query=SELECT i FROM Item i WHERE i.price > 100.0&consumeDelete=true")
    .to("mock:jpaResults");
----

XML::
+
[source,xml]
----
<bean id="hibernate" class="org.apache.camel.component.hibernate.HibernateComponent">
  <property name="entityManagerFactory" ref="entityManagerFactory"/>
</bean>
----

YAML::
+
[source,yaml]
----
- route:
    from:
      uri: direct:jpaPersist
      steps:
        - to:
            uri: hibernate:org.apache.camel.component.hibernate.Item
            parameters:
              usePersist: true
----
====

=== Native Hibernate mode example

from("hibernate:org.apache.camel.component.hibernate.Item?namedQuery=Item.findAll&maximumResults=10")

----

XML::
+
[source,xml]
----
<bean id="hibernate" class="org.apache.camel.component.hibernate.HibernateComponent">

</bean>

YAML::
