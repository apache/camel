The Hibernate component provides integration with relational databases through Hibernate ORM and Jakarta Persistence (JPA). It allows you to send Java objects to be persisted or merged in a database, run queries, and poll databases for recurring batch processing supporting both JPA-backed and Native Hibernate execution modes.

Maven users will need to add the following dependency to their `pom.xml`
for this component:

## [source,xml]

== URI format

---

## hibernate:entityClassName[?options]

Where `entityClassName` is the target entity class name or entity type name.

== Usage

=== Producer Operations

When acting as a producer, the Hibernate endpoint persists or queries entities depending on the Exchange message body or configured URI parameters:

* **Persist / Merge**: If the body contains an entity instance (or collection of entities), sending the exchange to the endpoint persists or updates the entity in the database.


* **Query Execution**: If a query is provided via URI options (`query`, `namedQuery`, or `nativeQuery`) or overridden via the `HibernateConstants.HIBERNATE_QUERY` header, the producer executes the query and returns the query result as the outbound body.



=== Consumer Operations

When acting as a consumer, the endpoint polls the database periodically using a configured query (`query`, `namedQuery`, or `nativeQuery`).

* **Consume and Delete**: Setting `consumeDelete=true` deletes consumed entities from the database after processing to avoid re-processing during subsequent polling cycles.


* **Maximum Results**: Use `maximumResults` to limit the number of records returned per poll batch.



== Execution Modes

The Hibernate component supports two primary operational infrastructure modes:

=== JPA-Backed Mode
In JPA-backed mode, the component leverages Jakarta Persistence (`EntityManagerFactory`) to perform operations via standard JPA or Spring-managed transaction strategies.

=== Native Hibernate Mode
In Native Hibernate mode, the component uses a native Hibernate `SessionFactory` directly, allowing you to execute queries or interact with sessions using pure Hibernate capabilities.

=== JPA-Backed Mode Example

The following example demonstrates how to configure and use the component in JPA-backed mode:

# [tabs]

## Java::
+
[source,java]

// Configure the component with an EntityManagerFactory
HibernateComponent component = new HibernateComponent();
component.setEntityManagerFactory(entityManagerFactory);
context.addComponent("hibernate", component);

// Define routes for JPA persistence and queries
from("direct:jpaPersist")
.to("hibernate:org.apache.camel.component.hibernate.Item?usePersist=true");

## from("hibernate:org.apache.camel.component.hibernate.Item?query=SELECT i FROM Item i WHERE i.price > 100.0&consumeDelete=true")
.to("mock:jpaResults");

## XML::
+
[source,xml]

=== Native Hibernate Mode Example

The following example demonstrates how to configure and use the component in Native Hibernate mode:

# [tabs]

## Java::
+
[source,java]

// Configure the component with a native Hibernate SessionFactory
HibernateComponent component = new HibernateComponent();
component.setSessionFactory(sessionFactory);
context.addComponent("hibernate", component);

// Define routes using native Hibernate queries or parameters
from("direct:nativePersist")
.to("hibernate:org.apache.camel.component.hibernate.Item");

## from("hibernate:org.apache.camel.component.hibernate.Item?namedQuery=Item.findAll&maximumResults=10")
.to("mock:nativeResults");
