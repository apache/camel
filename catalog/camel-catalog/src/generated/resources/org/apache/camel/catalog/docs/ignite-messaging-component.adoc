== Usage

The component needs an Ignite node: xref:ignite-summary.adoc[Ignite] describes the ways to give it one.

The producer sends the body to the `orders` topic, and the consumer receives the messages of that topic:

[source,yaml]
----
- route:
    from:
      uri: direct:publish
      steps:
        - to:
            uri: ignite-messaging:orders
- route:
    from:
      uri: ignite-messaging:orders
      steps:
        - log:
            message: "Received: ${body}"
----

The consumer sets the `CamelIgniteMessagingTopic` header to the topic it received a message on. While the header still
holds that topic, the producer sends to the topic of its endpoint, so a route from one topic to another sends each
message to the second topic, not back to the first one. A topic header set by the route is used. To send a received
message back to its topic through the header, remove the `CamelIgniteMessagingReceivedTopic` exchange property (which
the consumer sets to the received topic) before the producer, such as with
`.removeProperty(IgniteConstants.IGNITE_MESSAGING_RECEIVED_TOPIC)`.
