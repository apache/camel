The Kubernetes CronJob component is one of xref:kubernetes-summary.adoc[Kubernetes Components] which
provides a producer to execute kubernetes CronJob operations.

== Supported producer operation

- `listCronJob`
- `listCronJobByLabels`
- `getCronJob`
- `createCronJob`
- `updateCronJob`
- `deleteCronJob`

== Example

The following route lists the cron jobs of the cluster every minute.
The `kubernetesClient` bean is the client of the cluster, as in the other Kubernetes components:

[source,yaml]
----
- route:
    from:
      uri: timer:cronjobs
      parameters:
        period: 60000
      steps:
        - to:
            uri: kubernetes-cronjob:///
            parameters:
              kubernetesClient: "#kubernetesClient"
              operation: listCronJob
        - log:
            message: "The cluster has ${body.size()} cron jobs"
----
