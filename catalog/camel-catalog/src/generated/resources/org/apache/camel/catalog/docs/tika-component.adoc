:doctitle: Tika

:component-header: Only producer is supported

*Since Camel {since}*

*{component-header}*

The Tika component provides the ability to detect and parse documents with
Apache Tika. This component uses
https://tika.apache.org/[Apache Tika] as the underlying library to work
with documents.

To use the Tika component, Maven users will need to add the
following dependency to their `pom.xml`:

*pom.xml*

[source,xml]
----
<dependency>
    <groupId>org.apache.camel</groupId>
    <artifactId>camel-tika</artifactId>
    <version>x.x.x</version>
    <!-- use the same version as your Camel core version -->
</dependency>
----

== Usage

=== To Detect a file's MIME Type

The body is the document: text, bytes, a stream or a file. After `detect`, the body is the MIME type as text, such as
`text/html`.

[tabs]
====
Java::
+
[source,java]
----
from("direct:start")
        .to("tika:detect");
----

XML::
+
[source,xml]
----
<route>
  <from uri="direct:start"/>
  <to uri="tika:detect"/>
</route>
----

YAML::
+
[source,yaml]
----
- route:
    from:
      uri: direct:start
      steps:
        - to:
            uri: tika:detect
----
====

=== To Parse a File

The body is the document: text, bytes, a stream or a file. After `parse`, the body is a `ByteArrayOutputStream` with
the content as XHTML, or as HTML or plain text with `tikaParseOutputFormat`, which converts to a `String`, and the
metadata of the document are headers, such as `dc:title`. The component has the Tika parsers of HTML and text: other
types need their Tika parser module, such as `org.apache.tika:tika-parser-pdf-module` for PDF, or the content is empty.

The body of `detect` and `parse` must convert to an `InputStream`, such as a `java.io.File`, a `byte[]`, a `String` or
a stream. A missing body or a body that does not convert, such as a `Map`, fails with an `InvalidPayloadException`.

The `parse` operation writes its output in the `tikaParseOutputEncoding` and sets that encoding as the charset of the
exchange (the `CamelCharsetName` exchange property), so converting the output to a `String` decodes it right.

[tabs]
====
Java::
+
[source,java]
----
from("direct:start")
        .to("tika:parse");
----

XML::
+
[source,xml]
----
<route>
  <from uri="direct:start"/>
  <to uri="tika:parse"/>
</route>
----

YAML::
+
[source,yaml]
----
- route:
    from:
      uri: direct:start
      steps:
        - to:
            uri: tika:parse
----
====
