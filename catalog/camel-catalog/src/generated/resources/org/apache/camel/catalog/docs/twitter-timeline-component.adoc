= Twitter Timeline Component
:doctitle: Twitter Timeline
:shortname: twitter-timeline
:artifactid: camel-twitter
:description: Send tweets and receive tweets from user's timeline.
:since: 2.10
:supportlevel: Stable
:tabs-sync-option:
:component-header: Both producer and consumer are supported

*Since Camel {since}*

*{component-header}*

The Twitter Timeline component consumes twitter timeline or updates the status of specific user.

The `timelineType` is one of:

* `home`
* `mentions`
* `user`, with the `user` option
* `list`, with the `user` and `list` options

A consumer reads the timeline. A producer must use `user`: it tweets the message body as the status of the account.

== Usage

The credentials of the Twitter application are component options, for example in `application.properties`:

[source,properties]
----
camel.component.twitter-timeline.consumer-key = {{env:TWITTER_CONSUMER_KEY}}
camel.component.twitter-timeline.consumer-secret = {{env:TWITTER_CONSUMER_SECRET}}
camel.component.twitter-timeline.access-token = {{env:TWITTER_ACCESS_TOKEN}}
camel.component.twitter-timeline.access-token-secret = {{env:TWITTER_ACCESS_TOKEN_SECRET}}
----

The following route polls the home timeline every minute, and logs the text of each tweet:

[source,yaml]
----
- route:
    from:
      uri: twitter-timeline:home
      parameters:
        delay: 60000
      steps:
        - log:
            message: "${body.text}"
----

The following route tweets the message body:

[source,yaml]
----
- route:
    from:
      uri: direct:tweet
      steps:
        - to:
            uri: twitter-timeline:user
----
