This is a component for Apache Camel that allows for
Producing/Consuming PostgreSQL events related to the LISTEN/NOTIFY
commands added since PostgreSQL 8.3.

Maven users will need to add the following dependency to their `pom.xml`
for this component:

[source,xml]
------------------------------------------------------------
<dependency>
    <groupId>org.apache.camel</groupId>
    <artifactId>camel-pgevent</artifactId>
    <version>x.x.x</version>
    <!-- use the same version as your Camel core version -->
</dependency>
------------------------------------------------------------

== URI format

The pgevent component uses the following two styles of endpoint URI
notation:

-------------------------------------------------
pgevent:datasource[?parameters]
pgevent://host:port/database/channel[?parameters]
-------------------------------------------------

== Usage

=== Listening and notifying

The consumer listens on a channel (`LISTEN`), and the message body is the payload of each notification.
The producer sends the message body as the payload of a notification on the channel (`NOTIFY`):

[source,yaml]
----
- route:
    from:
      uri: pgevent://localhost:5432/mydb/orders
      parameters:
        user: postgres
        pass: "{{pg.password}}"
      steps:
        - log:
            message: "Notification on channel orders: ${body}"
- route:
    from:
      uri: timer:notify
      parameters:
        period: 5000
      steps:
        - setBody:
            expression:
              simple:
                expression: "new order at ${date:now:HH:mm:ss}"
        - to:
            uri: pgevent://localhost:5432/mydb/orders
            parameters:
              user: postgres
              pass: "{{pg.password}}"
----

=== Common problems

==== Unable to connect to PostgreSQL database using DataSource
Using the driver provided by PostgreSQL itself (`jdbc:postgresql:/...`) when using a DataSource to connect to a PostgreSQL database does not work.

Please use the pgjdbc-ng driver (`jdbc:pgsql:/...`) instead.
