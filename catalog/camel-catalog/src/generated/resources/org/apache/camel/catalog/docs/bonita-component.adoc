== Usage

=== Body content

For the startCase operation, the input variables are retrieved from the body message.
This one has to contain a `Map<String,Serializable>`, or a JSON object as text (`String`, `byte[]` or `InputStream`)
such as `{"amount": 1}`, which is parsed into that `Map`.
Any other body, also JSON text that is not an object (such as a JSON array), fails with an `InvalidPayloadException`.

After the operation, the body is still the `Map` of the inputs, or the JSON text that was sent.
The id of the started case is set in the `CamelBonitaCaseId` header.

=== Using HTTPS

By default, the producer calls the REST API of Bonita over plain HTTP. The username and password of the login, the
session cookies and the `X-Bonita-API-Token` header travel in clear text.
Set the `protocol` option to `https` to send them over TLS, and set `port` to the HTTPS port of the Bonita server.

When the JVM does not trust the certificate of the Bonita server, configure a trust store with the
`sslContextParameters` option (or with the global SSL context parameters of Camel and the
`useGlobalSslContextParameters` option of the component). The login and all the requests of the producer use this
SSL context. Without it, the JAX-RS runtime uses the default SSL context of the JVM. The `http` protocol ignores it.

[source,java]
----
from("direct:start")
    .to("bonita:startCase?protocol=https&hostname=bonita.example.com&port=8443&processName=TestProcess"
        + "&username=install&password=install&sslContextParameters=#bonitaSsl");
----


== Examples

The following example starts a new case in Bonita:

[tabs]
====
Java::
+
[source,java]
----
from("direct:start").to("bonita:startCase?hostname=localhost&port=8080&processName=TestProcess&username=install&password=install");
----

XML::
+
[source,xml]
----
<route>
  <from uri="direct:start"/>
  <to uri="bonita:startCase?hostname=localhost&amp;port=8080&amp;processName=TestProcess&amp;username=install&amp;password=install"/>
</route>
----

YAML::
+
[source,yaml]
----
- route:
    from:
      uri: direct:start
      steps:
        - to:
            uri: bonita:startCase
            parameters:
              hostname: localhost
              port: 8080
              processName: TestProcess
              username: install
              password: install
----
====

== Dependencies

To use Bonita in your Camel routes, you need to add a dependency on
*camel-bonita*, which implements the component.

If you use Maven, you can add the following to your pom.xml,
substituting the version number for the latest and greatest release (see
the download page for the latest versions).

[source,xml]
-------------------------------------
<dependency>
  <groupId>org.apache.camel</groupId>
  <artifactId>camel-bonita</artifactId>
  <version>x.x.x</version>
</dependency>
-------------------------------------
