:artifactid: camel-asterisk
:description: Receive events from an Asterisk PBX server and send actions to it over the Asterisk Manager Interface (AMI).

*Since Camel {since}*

*{component-header}*

The Asterisk component allows you to work easily with an Asterisk PBX Server http://www.asterisk.org/ using https://asterisk-java.org/[asterisk-java]

This component helps to interface with http://www.voip-info.org/wiki-Asterisk+manager+API[Asterisk Manager Interface]

Maven users will need to add the following dependency to their `pom.xml`
for this component:

[source,xml]
------------------------------------------------------------
<dependency>
    <groupId>org.apache.camel</groupId>
    <artifactId>camel-asterisk</artifactId>
    <version>x.x.x</version>
    <!-- use the same version as your Camel core version -->
</dependency>
------------------------------------------------------------

== Action

Supported actions are:

* QUEUE_STATUS: Queue status
* SIP_PEERS: List SIP peers
* EXTENSION_STATE: Check extension status

QUEUE_STATUS and SIP_PEERS are answered with a list of events. The producer waits for the whole list and sets
the `org.asteriskjava.manager.ResponseEvents` as the message body: `getResponse()` is the response of Asterisk,
and `getEvents()` the events of the list, such as `QueueParamsEvent` and `QueueMemberEvent` for QUEUE_STATUS or
`PeerEntryEvent` for SIP_PEERS, ending with the complete event (`QueueStatusCompleteEvent` or
`PeerlistCompleteEvent`). To route each event on its own, split on `${body.events}`.

EXTENSION_STATE sets the `ManagerResponse` (an `ExtensionStateResponse`) as the message body.
When Asterisk answers with an error, the response is a `ManagerError`.

== TLS

By default the consumer and the producer connect to the Asterisk Manager Interface (AMI) over plain TCP, so the
username, the password, the actions and the events are sent in clear text. Set `ssl=true` to connect over TLS:

[source,java]
----
from("asterisk:myVoIP?hostname=hostname&username=username&password=password&ssl=true")
  .log("Received a message - ${body}");
----

The Asterisk server must accept AMI over TLS on the port that the component connects to: set `tlsenable=yes` and
the `tlsbindaddr` address in the `[general]` section of `manager.conf`, together with the certificate of the server
(`tlscertfile` and `tlsprivatekey`).

asterisk-java opens the TLS socket with the default `SSLSocketFactory` of the JVM, so the certificate of the server
is checked with the default trust store of the JVM. When the certificate is not signed by a certificate authority that
the JVM trusts, add it to a trust store and point the JVM to it with the `javax.net.ssl.trustStore` and
`javax.net.ssl.trustStorePassword` system properties. A custom `SSLContextParameters` is not supported, and the host
name of the server is not checked against the certificate.

== Examples

=== Producer Example

[tabs]
====
Java::
+
[source,java]
----
from("direct:in")
  .to("asterisk://myVoIP?hostname=hostname&username=username&password=password&action=EXTENSION_STATE");
----

XML::
+
[source,xml]
----
<route>
  <from uri="direct:in"/>
  <to uri="asterisk://myVoIP?hostname=hostname&amp;username=username&amp;password=password&amp;action=EXTENSION_STATE"/>
</route>
----

YAML::
+
[source,yaml]
----
- route:
    from:
      uri: direct:in
      steps:
        - to:
            uri: asterisk://myVoIP
            parameters:
              hostname: hostname
              username: username
              password: password
              action: EXTENSION_STATE
----
====

=== Consumer Example

[tabs]
====
Java::
+
[source,java]
----
from("asterisk:myVoIP?hostname=hostname&username=username&password=password")
  .log("Received a message - ${body}");
----

XML::
+
[source,xml]
----
<route>
  <from uri="asterisk:myVoIP?hostname=hostname&amp;username=username&amp;password=password"/>
  <log message="Received a message - ${body}"/>

----

YAML::
+
[source,yaml]
----
- route:
    from:
      uri: asterisk:myVoIP
      parameters:
        hostname: hostname
        username: username
        password: password
      steps:

----
