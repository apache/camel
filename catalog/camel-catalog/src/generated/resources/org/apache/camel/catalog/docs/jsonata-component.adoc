= JSONata Component
:doctitle: JSONata
:shortname: jsonata
:artifactid: camel-jsonata
:description: Transforms JSON payload using JSONata transformation.
:since: 3.5
:supportlevel: Stable
:tabs-sync-option:
:component-header: Only producer is supported

*Since Camel {since}*

*{component-header}*

The Jsonata component allows you to process JSON messages using the
https://jsonata.org/[JSONATA] specification. This can be
ideal when doing JSON to JSON transformation and other transformations from JSON.

Maven users will need to add the following dependency to
their `pom.xml` for this component:

[source,xml]
----
<dependency>
    <groupId>org.apache.camel</groupId>
    <artifactId>camel-jsonata</artifactId>
    <version>x.x.x</version>
    <!-- use the same version as your Camel core version -->
</dependency>
----
 

== URI format

----
jsonata:specName[?options]
----

Where *specName* is the classpath-local URI of the specification to
invoke; or the complete URL of the remote specification
(e.g.: `\file://folder/myfile.vm`).

== Examples

=== Basic

For example, you could use something like:

The messages of the queue are JSON text, so the examples set `inputType` and `outputType` to `JsonString`: with the default, `Jackson`, the body must be JSON data (a Map, a List or a JsonNode), such as after `unmarshal: json`, and the result is a JsonNode.

[tabs]
====
Java::
+
[source,java]
----
from("activemq:My.Queue")
    .to("jsonata:com/acme/MyResponse.json?inputType=JsonString&outputType=JsonString");
----

XML::
+
[source,xml]
----
<route>
  <from uri="activemq:My.Queue"/>
  <to uri="jsonata:com/acme/MyResponse.json?inputType=JsonString&amp;outputType=JsonString"/>
</route>
----

YAML::
+
[source,yaml]
----
- route:
    from:
      uri: activemq:My.Queue
      steps:
        - to:
            uri: jsonata:com/acme/MyResponse.json
            parameters:
              inputType: JsonString
              outputType: JsonString
----
====

And a file-based resource:

[tabs]
====
Java::
+
[source,java]
----
from("activemq:My.Queue")
    .to("jsonata:file://myfolder/MyResponse.json?contentCache=true&inputType=JsonString&outputType=JsonString")
    .to("activemq:Another.Queue");
----

XML::
+
[source,xml]
----
<route>
  <from uri="activemq:My.Queue"/>
  <to uri="jsonata:file://myfolder/MyResponse.json?contentCache=true&amp;inputType=JsonString&amp;outputType=JsonString"/>
  <to uri="activemq:Another.Queue"/>
</route>
----

YAML::
+
[source,yaml]
----
- route:
    from:
      uri: activemq:My.Queue
      steps:
        - to:
            uri: jsonata:file://myfolder/MyResponse.json
            parameters:
              contentCache: true
              inputType: JsonString
              outputType: JsonString

            uri: activemq:Another.Queue
----

=== Frame bindings

It is possible to configure custom functions that can be called from Jsonata. For example you might want to be able to
inject environment variables:

[tabs]
====
Java::
+
[source,java]
----
from("activemq:My.Queue")
    .to("jsonata:file://myfolder/MyResponse.json?contentCache=true&inputType=JsonString&outputType=JsonString&frameBinding=#customBindings")
    .to("activemq:Another.Queue");
----

XML::
+
[source,xml]
----
<route>
  <from uri="activemq:My.Queue"/>
  <to uri="jsonata:file://myfolder/MyResponse.json?contentCache=true&amp;inputType=JsonString&amp;outputType=JsonString&amp;frameBinding=#customBindings"/>
  <to uri="activemq:Another.Queue"/>
</route>
----

YAML::
+
[source,yaml]
----
- route:
    from:
      uri: activemq:My.Queue
      steps:
        - to:
            uri: jsonata:file://myfolder/MyResponse.json
            parameters:
              contentCache: true
              inputType: JsonString
              outputType: JsonString
              frameBinding: "#customBindings"
        - to:
            uri: activemq:Another.Queue
----
====

A custom binding might look like the following:

._Java-only: implementing a custom JsonataFrameBinding_
[source,java]
----
@NoArgsConstructor
public class CustomJsonataFrameBinding implements JsonataFrameBinding {
  @Override
  public void bindToFrame(Jsonata.Frame frame) {
    frame.bind("env", (String s) -> System.getenv(s));
  }
}
----
