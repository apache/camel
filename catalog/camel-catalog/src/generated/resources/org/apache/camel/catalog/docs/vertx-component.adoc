*Since Camel {since}*

*{component-header}*

The Vert.x component is for working with the http://vertx.io/[Vertx]
https://vertx.io/docs/vertx-core/java/#event_bus[EventBus].

The vertx https://vertx.io/docs/vertx-core/java/#event_bus[EventBus]
sends and receives JSON events.

Maven users will need to add the following dependency to their `pom.xml`
for this component:

[source,xml]
----
<dependency>
    <groupId>org.apache.camel</groupId>
    <artifactId>camel-vertx</artifactId>
    <version>x.x.x</version>
    <!-- use the same version as your Camel core version -->
</dependency>
----

== Usage

The producer sends the message body to the event bus address, and a consumer of that address receives it.
A message goes to one consumer, or to all consumers with `pubSub`:

[source,yaml]
----
- route:
    from:
      uri: timer:orders
      parameters:
        period: 5000
      steps:
        - setBody:
            expression:
              constant:
                expression: '{"orderId": 123}'
        - to:
            uri: vertx:orders
            parameters:
              pubSub: true
- route:
    from:
      uri: vertx:orders
      steps:
        - log:
            message: "Received order ${body}"
----

When the exchange is InOut, the producer sends a request and the reply of the consumer becomes the message body:

[source,yaml]
----
- route:
    from:
      uri: direct:greet
      steps:
        - to:
            uri: vertx:greeter
            pattern: InOut
        - log:
            message: "The reply is ${body}"
- route:
    from:
      uri: vertx:greeter
      steps:
        - setBody:
            expression:
              simple:
                expression: "Hello ${body}"
----

== Connecting to the existing Vert.x instance

If you would like to connect to the Vert.x instance already existing in
your JVM, you can set the instance on the component level:

._Java-only: connecting to an existing Vert.x instance_
[source,java]
----
Vertx vertx = ...;
VertxComponent vertxComponent = new VertxComponent();
vertxComponent.setVertx(vertx);
camelContext.addComponent("vertx", vertxComponent);
----
