== Deterministic simulation tests

The consumer of the {doctitle} component is tested with xref:others:test-dst.adoc[deterministic simulation tests]:
the real consumer runs under a seeded virtual-time scheduler against a fake of the external system, which injects
faults while the tests check invariants. A failing seed can be replayed. These are the fake worlds of the component:

|===
| World | What it checks | Issues
|===

The worlds and their tests are in the test sources of the component. How to run them, replay a seed and write a
world is described in xref:others:test-dst.adoc#_running_the_tests[Running the tests] and
