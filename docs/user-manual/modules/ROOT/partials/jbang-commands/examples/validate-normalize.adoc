== Examples

The command parses YAML routes and rewrites them in canonical form, expanding all shorthands and
implicit expressions. The normalized output is valid against both the classic and canonical schemas.
See xref:components:others:yaml-dsl.adoc[YAML DSL] for the differences between the classic and canonical schemas.

Normalize a YAML route and print to console:

[source,bash]
----
camel validate normalize myroute.yaml
----

Normalize and write to a file:

[source,bash]
----
camel validate normalize --output normalized.yaml myroute.yaml
----

Normalize multiple files into a directory:

[source,bash]
----
camel validate normalize --output normalized/ routes/*.yaml
----

=== Before and after

Given the following YAML route using classic shorthands:

[source,yaml]
----
- route:
    from:
      uri: timer:yaml
      steps:
        - setBody:
            simple: "Hello Camel from ${routeId}"
        - log: "${body}"
----

Running `camel validate normalize myroute.yaml` produces the canonical form:

[source,yaml]
----
- route:
    from:
      uri: timer:yaml
      steps:
        - setBody:
            expression:
              simple:
                expression: "Hello Camel from ${routeId}"
        - log:
            message: "${body}"
----
